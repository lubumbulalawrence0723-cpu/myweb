# Lawrence Lubumbula - Student Portfolio

This personal portfolio introduces Lawrence Lubumbula, a Cyber Security student at Mulungushi University. It keeps the original Activity 2 biography, hobbies, learning plan, photos, video, and audio, and adds an interactive skills section and contact-form demonstration.

## JavaScript features

1. **Contact form validation and preview:** checks the name, email, and message, rejects whitespace-only required fields and invalid email addresses, then displays a local preview. It does not send a message.
2. **Photo viewer:** Previous and Next change the featured photo and caption. The gallery wraps from the last photo to the first and from the first to the last.
3. **Project and skills filter:** searches three portfolio examples, has a Reset button, and explains when there are no matches.
4. **Theme switch:** switches between light and dark colour palettes.

## Run and test locally

Open the project folder in VS Code and start it with Live Server by opening `index.html` and selecting **Go Live**.

- Use the navigation links and check that each section opens.
- Search for `HTML`, then a word with no matches; use Reset to show all three cards again.
- Use Previous on the first photo and Next on the last photo to check that the gallery wraps correctly.
- Switch themes and confirm text, links, buttons, and fields remain readable.
- Submit the contact form empty, with spaces in the name or message, with an invalid email, and with valid values. The valid case should show a preview and say that no message was sent.
- Use Tab to reach the navigation, feature buttons, media controls, and form fields. Check that focus is visible.
- Test the page at about 375 px and 1280 px wide. Confirm it has no sideways page scrolling and that the photos, video, and audio load.
- Check the browser Console for JavaScript errors and missing files.

## Sources and media

No external libraries, fonts, or stock images are used. The photos, video, and audio are the personal media supplied with the original website.
